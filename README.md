# Two Screen App

## Project Overview
A simple Android app developed using Kotlin and XML for the Veda Technology Android Development Track (Day 11). It demonstrates navigation between two activities using an Explicit Intent.

## Technologies Used
- Kotlin
- XML Layouts
- Android Studio

## Features
- First screen with a button
- Second screen with a welcome message
- Navigation using Intent

## How to Run
1. Clone the repository. 2. Open in Android Studio. 3. Sync Gradle. 4. Run the app.

## Outcome
The application successfully navigates from the first screen to the second screen using an Explicit Intent.
